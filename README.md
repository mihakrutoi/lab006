### 1. Статистика (`statistics.py`)
* **Входные данные:** `-2 0 5 3`
  * **Ожидаемый результат:** количество `4`, сумма `6`, минимум `-2`, максимум `5`, среднее `1.50`
  * **Фактический результат:** Совпадает с ожидаемым.
* **Входные данные:** `8`
  * **Ожидаемый результат:** количество `1`, сумма `8`, минимум `8`, максимум `8`, среднее `8.00`
  * **Фактический результат:** Совпадает с ожидаемым.
* **Входные данные:** `""` (пустой ввод)
  * **Ожидаемый результат:** `Нет данных`
  * **Фактический результат:** Совпадает с ожидаемым.

  * **Фактический результат:** Совпадает с ожидаемым.
* **Входные данные (дополнительный непустой набор):** `4 2 -6 8 0 3`

* **Входные данные:** `""` (пустой ввод)

  * **Фактический результат:** Совпадает с ожидаемым.
* **Входные данные (ввод без совпадений):** `-2 -4 1 3 5`
  * **Ожидаемый результат:** Выборка: `[]`, количество `0`, ...
